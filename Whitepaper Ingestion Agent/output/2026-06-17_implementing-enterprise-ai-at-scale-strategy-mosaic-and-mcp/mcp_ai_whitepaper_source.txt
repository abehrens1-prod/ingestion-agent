[P] VI. Security and Governance: Making AI Safe by Default
[P] The Inherited Security Model
[P] Traditional AI implementations face a painful tradeoff: grant broad access to enable useful
[P] answers or lock down data and cripple the AI's capabilities. Strategy eliminates this tradeoff
[P] through security inheritance.
[BOLD] How It Works:
[P] 1.User authenticates to Strategy (via OAuth 2.0)
[P] 2.Strategy loads that user’s row-level security rules, column permissions, and domain access
[P] 3.MCP connection inherits those permissions automatically
[P] 4.AI queries execute within the security boundary—no additional configuration needed
[P] Result: An AI agent running as a Sales Manager sees only their territories. The
[P] same agent, running as a VP of Sales, sees the entire sales organization.
[P] Same code, different security context.
