### The Brief (review before publishing)

1. **Mosaic Model Linking delivers up to 90% reduction in time to deliver new cross-domain analysis.** By connecting independently managed semantic models through shared business entities, organizations eliminate the need for custom integrations and manual reconciliation between domain models. This also yields up to 90% fewer duplicate definitions for shared entities like Employee, Customer, and Date.
2. **Row-level and object-level security policies remain fully enforced across all linked models without requiring duplication.** When queries span independently governed models, every applicable security restriction stays active throughout the linked analysis. Teams do not need to recreate security rules in every model that consumes linked data, making Model Linking suitable for regulated industries such as healthcare, financial services, and government.
3. **Shared business entities must meet six technical requirements to ensure reliable query results across linked models.** Consistent business meaning, aligned analytical grain, known cardinality, compatible key formats, an authoritative value source, and stable ownership with change control are all required. Inconsistent definitions across these dimensions can cause queries to fail silently or return incorrect aggregated results.
